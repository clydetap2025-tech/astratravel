# AstraTravel

Путеводитель по Казахстану: 17 городов и 90 мест — от Байтерека и мавзолея Ясави до Бозжыры и Баянаула. В Алматы есть подборка тематических кафе для гостей из 13 стран (из Японии — Ramen 77, из Индии — Tandoor и так далее). Интерфейс на русском, казахском, английском и японском.

Всё, кроме ИИ, работает без входа: каталог по городам, знакомство с глобусом, билеты между 17 аэропортами, избранное, маршрут по каталогу и живая карта Алматы. Заметки ИИ к маршруту доступны после входа.

## Запуск

Для серверной версии нужен Node.js 22.13 или новее. Установите зависимости по файлу блокировки и запустите приложение.

```sh
npm ci
npm start
```

Откройте `http://localhost:3000`. При необходимости задайте `PORT`. Каталог, глобус, поиск деморейсов, избранное и маршрут по каталогу доступны гостю. Для заметок ИИ можно войти в демо-аккаунт или создать аккаунт с логином и паролем. Сервер хранит хеши паролей и сессии в SQLite в каталоге `.data/`.

`npm run build:demo` создаёт самодостаточный `public/index.html`. Файл открывается в браузере с диска и содержит каталог, примеры рейсов и планировщик с демонстрационным входом. Главная страница видна даже в предпросмотре с отключённым JavaScript.

## Vercel

`vercel.json` собирает фронтенд статикой (`scripts/vercel-build.mjs` → `dist/client`), а запросы `/api/*` передаёт функции `api/index.mjs` с тем же обработчиком, что и у `server.mjs`. На Vercel писать можно только во временную папку, поэтому база SQLite (аккаунты и сессии) живёт там и пропадает при перезапуске функции. Для постоянных аккаунтов нужна внешняя база.

## Экраны

Первый визит начинается со знакомства (`#welcome`, `src/Onboarding.tsx`): одно решение на экран, шаги сменяются по направлению движения.

1. **Заставка** (`src/components/ui/sketch-city-hero.tsx`): заголовок по словам, счётчики и нарисованная панорама Алматы (`almaty-art.tsx`).
2. **Язык**: смена текста — плавная, через View Transitions (или CSS-затухание).
3. **Гость или местный.**
4. **Откуда**: гостю — список стран; местному — район города (`data/districts.js`), откуда живая карта вызывает такси.
5. **Интересы**: попадают в подборку и в планировщик.
6. **Подборка**: гостю — «Вкус дома» и главное в городе, местному — выезды на выходные и кухни мира.

Дальше открывается каталог с полосой «Для вас», а знакомство можно пройти заново кнопкой «Изменить». **Живая карта** (`city-lens.tsx`) — на странице маршрута.

## Оформление

Стиль Liquid Glass: шапка, панели, кнопки, поля, диалоги и карточки — стекло поверх медленно «дышащего» фона. Навигация — `LiquidNavbar` (Nimbus UI «Waterline», guglielmogiannattasio.it) с водяной каплей на WebGL; на телефоне она плавает внизу. Переключатель темы — стеклянная капсула «светлая / системная / тёмная», тема раскрывается кругом от нажатия. Логотип — капля со звездой (`src/components/ui/logo.tsx`).

Первый экран — глобус маршрутов (`src/components/ui/route-globe.tsx`, Canvas 2D, без WebGL и зависимостей): суша точками, контур Казахстана и рейсы из выбранного города во все остальные — по каждой дуге бежит «комета», точка прибытия пульсирует. Город выбирается нажатием на его точку или в списке; глобус поворачивается к нему, а при наведении показывает расстояние. Цвета следуют теме сайта. Переходы: страницы скользят по направлению меню, карточка места «перетекает» в окно (View Transitions), сетка мест плавно перестраивается при фильтрах. У мест без фото — оформленные обложки по категории.

Заголовки — Literata, интерфейс — Golos Text (оба с казахскими буквами, OFL). Учитываются `prefers-reduced-motion`, `prefers-contrast: more` и `prefers-color-scheme`.

## База городов

`data/kazakhstan.js` — города (с аэропортом и координатами) и достопримечательности. В базу вошли только известные публичные места; адреса даны ориентирами, без номеров домов; цена указана только там, где она известна (0 — свободный вход), иначе карточка пишет «Цену уточняйте». Источник каждого места — поиск по Википедии. У мест вне Алматы нет фотографий: вместо них рисунки по категории.

## Приложение на телефоне и компьютере

Сайт устанавливается как PWA (`public/manifest.webmanifest`, `public/sw.js`): иконки для Android, iOS и десктопа, работа без сети после первого визита, отступы под вырез экрана и жесты. Анимации отключаются при «уменьшении движения» в системе, без JavaScript главная показывается в готовом виде, а при «уменьшении движения» глобус рисуется неподвижным.

## Supabase

Схема для городов, мест, аккаунтов, избранного, сохранённых маршрутов и учёта ИИ-запросов лежит в `supabase/migrations/`, данные каталога — в `supabase/seed.sql`. Сид собирается из `data/*.js`, поэтому после правки каталога выполните `node scripts/supabase-seed.mjs`.

```sh
supabase init          # создаёт supabase/config.toml, миграции не трогает
supabase link --project-ref <ref>
supabase db push       # применяет миграции
psql "$DATABASE_URL" -f supabase/seed.sql
```

Каталог открыт на чтение всем. Таблицы пользователей закрыты RLS: каждый видит и меняет только свои строки. Запросы к ИИ записывает сервер с service-role ключом в `ai_requests`, а `ai_requests_left()` показывает, сколько запросов осталось в текущем часе. Само приложение пока использует вход из `server.mjs` (SQLite); подключение Supabase Auth — следующий шаг.

## Исходники

- `src/` содержит React-компоненты и типы TypeScript. `npm run typecheck` проверяет типы.
- `public/styles.css` содержит стили и адаптивную верстку.
- `data/` и `lib/` содержат данные, переводы, планировщик и серверную логику на JavaScript.

## Маршрут

Планировщик подбирает места из каталога с учётом дней, бюджета и интересов прямо в браузере, без входа. Последний маршрут сохраняется на устройстве. Загородная поездка занимает отдельный день. Готовый маршрут с адресами и советами можно скачать как текст и читать без связи.

Кнопка «Улучшить с ИИ» работает после входа. Если серверу передан `OPENAI_API_KEY`, он запрашивает краткие заметки к составленному маршруту через Responses API. По умолчанию используется `gpt-4.1-mini`, модель можно изменить через `OPENAI_MODEL`. Ключ задаётся на сервере. При отсутствии ключа или сбое API остаётся план по каталогу, и приложение об этом сообщает.

## Данные прототипа

- `data/catalog.js` содержит места, описания на четырёх языках, источники, длительность посещения, ориентиры расходов и правила рекомендаций по стране выезда. Адреса новых кафе взяты из открытых карт и страниц заведений — перед визитом их стоит проверить.
- `data/travellers.js` — точки на глобусе и демо-отзывы (люди и цитаты вымышлены, координаты городов настоящие). `data/map-points.js` — положение мест на схеме живой карты.
- `data/tickets.js` задаёт демонстрационные рейсы и цены. Искать можно между шестью городами Казахстана, менять дату и сортировать результаты.
- Избранное и параметры поездки хранятся в браузере. Цены и иллюстрации в демо даны для примера.
- `npm run build` собирает Worker для Sites. В этой версии планировщик проверяет вход через Sites.
